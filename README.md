# Feng's C语言练习器

**ver1.2.1 · Windows 离线 C 语言练习与自动评测工具**

> By Feng; 仅供学习使用。

提供 **90 道普通练习 + 50 关星轨暗域**，内置 C 编译器、语法着色、随机评测、详细知识讲解与标准答案。

## ver1.2.1 更新

- **暗域降低起步难度**：从与普通练习30～40题相近的循环与数位处理起步，逐步进入数组、字符串、矩阵、常用算法及小项目；每关 **8～30 分钟**。
- **顶部横向星座导航**：50颗星点、波浪连线、当前星点光环与五章分隔；支持箭头、滚轮和滚动条。倒计时中保持深色并锁定选关，修复列表变白。
- **逐关详细提示**：学习目标、语法讲解、解题步骤、常见错误与边界检查，完整答案仍在通关后开放。
- **设置弹窗**：集中管理六档代码字号、自动检查开关、手动更新与GitHub地址；普通练习和暗域共享字号，设置自动保存。
- **检查更新与直接更新**：启动后后台读取正式Release；发现新版后，由用户在设置里手动下载并更新。核对文件大小、SHA-256及内嵌版本后，重启替换并保留原EXE备份。
- **界面优化**：深蓝渐变、统一卡片和下拉框、六档字号按钮，保留主窗口约0.8秒、弹窗约0.5秒淡入。

## 普通练习

60道基础题、27道进阶题和3道综合项目考试，覆盖输入输出、条件、循环、数组、字符串、函数、指针、递归、数据结构与算法。

每题有知识点与解题提示，先展开提示再查看答案，支持一键导入和原草稿备份。代码支持语法着色、行号、多步撤回与重做（Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z），字号在设置中调整。

按Ctrl+Enter编译评测；每题8组边界和20组随机测试。右侧显示输入、实际输出、预期输出、耗时及中英文诊断，完整报告可导出。编译/运行失败或低于60分显示得分警告；高分播放1秒庆祝动画。自动保存草稿与历史最高分，累计总分 / 9000。

## 暗域 · 星轨闯关

| 章节 | 关卡 | 学习重点 |
| --- | --- | --- |
| 微光初醒 | 01–10 | 循环、数位、质数、递推与统计 |
| 星屑阵列 | 11–20 | 数组、查找、分类、排序、旋转与命令 |
| 符文回廊 | 21–30 | 字符串、二维数组与矩阵 |
| 星轨推演 | 31–40 | 直观算法、区间、窗口与枚举 |
| 深空试炼 | 41–50 | 常用算法、状态管理与综合项目 |

从空白自主键入代码，禁止粘贴、拖入与答案导入；自己的草稿可保留重试。只有得分 **严格大于90分**且编译、运行正常才解锁下一关，90分整不能通关。答案仅通关后用于复盘。

点击开始后计时；学习、设置、切换窗口和离开界面仍按真实截止时间计时，评测耗时不计入答题时间。暗域保留失败动画，Esc可提前淡出。累计总分 / 5000。

## 设置与更新

设置中提供14、16、18、20、22、24六档字号按钮。点击即时生效，同步两个编辑器。

自动检查的成功结果缓存6小时，运行中每小时检查缓存时效；可手动立即检查。更新无需登录，不上传代码、草稿、成绩或进度。用户确认更新后下载官方Release附件，校验通过再启动更新助手。

更新需要EXE所在目录可写。更新助手等待旧进程退出，同目录原子替换，保留 `.exe.previous` 备份，再启动新版；启动指令失败时尝试还原。目录不可写时可从设置打开下载目录，另存新版后运行。校验失败不替换程序，联网失败不影响本地练习。

## 评分

每题100分：随机正确性60、边界正确性20、运行质量10、简洁度10。有效代码行数和大小各占5分，与参考答案比较并留有余量。详细规则见 [评分细则](CHANGELOG.md#评分细则)。

每组执行限制3秒、256 MiB，输出上限约64 KiB。整数精确比较，浮点绝对误差不超过0.0001。运行本地代码使用当前用户权限，资源限制不构成完整安全隔离。

## 从源码构建

在Windows PowerShell执行：

```powershell
./source/build.ps1
```

使用系统.NET Framework C#编译器，生成根目录的 `Feng_C语言练习器_ver1.2.1.exe`。TinyCC、AvalonEdit、图标与动画素材均随源码提供。

| 文件 | 用途 |
| --- | --- |
| `source/AppWpf.cs`、`CodeEditor.cs` | 普通练习与代码编辑 |
| `source/ChallengeCurriculum.cs` | 新版50关课程、提示及测试生成 |
| `source/ChallengeBank.cs` | 复用的既有题型与独立预期结果 |
| `source/ConstellationMap.cs`、`ChallengeWindow.cs` | 星座导航、计时与解锁 |
| `source/SettingsWindow.cs`、`AppSettings.cs` | 设置界面与本地偏好 |
| `source/UpdateService.cs` | Release检查、下载校验与更新助手 |
| `source/Engine.cs`、`CodeMetrics.cs` | 编译、运行、评测及评分 |

## 验证与数据兼容

ver1.2.1通过 **2800组暗域用例 + 112组普通练习抽查**，两种模式6档字号、3档DPI布局下共 **2988个字符位置命中**。另验证了实际GitHub下载校验和隔离更新助手替换流程。普通练习未重复执行全部90题基线；详见 [验证报告](docs/验证报告.txt)。
