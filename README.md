# Feng's C语言练习器

**ver1.3 · Windows 离线 C 语言练习与自动评测工具**

> By Feng · 仅供学习使用

内置 C 编译器、90道普通练习、50关暗域挑战、知识点学习和参考答案，提供代码编辑、语法着色、随机评测、错误分析和报告。

- [完整发布包：EXE、源码、使用说明、预览及验证记录](https://github.com/relsx/feng-c-practice/releases/download/ver1.3/Feng_C_Practice_ver1.3_full.zip)

旧版用户可在 **设置 → 检查更新** 获取本版，更新会保留原有草稿、成绩与暗域进度。手动检查可刷新自动检查的6小时缓存。

## ver1.3 新增

- **错题本**：记录编译失败和未通过用例，保存失败代码，支持搜索、筛选和复练；全用例通过后标为已解决。普通题恢复代码前会备份草稿。
- **失败用例对比**：预期与实际输出并排展示，突出首个不同项，可显示空格、制表符和换行。
- **自定义输入**：打开编码区终端图标试跑当前代码，显示原始输出、耗时和退出码；不计分、不解锁。
- **点击错误跳转**：点击原始编译诊断行或使用定位图标，返回对应代码行列并恢复编辑焦点。
- **中文 / English**：在设置中随时切换并保存默认语言，题目与知识点也提供英文内容；代码、输入输出、撤回历史和倒计时保持不变。

继续保留蓝白/夜蓝玻璃界面、独立界面与代码字号、自动保存、多步撤回/重做、普通题参考答案和软件内一键更新。

## 练习与闯关

普通练习选题后编写程序，按Ctrl+Enter正式评测。右侧显示输入、输出和诊断，可打开双栏对比及完整报告。答案先给提示再展开。

暗域50关限时8～30分钟，难度递增。全部代码须自主键入，通关前答案锁定；严格大于90分且编译、运行正常才可进入下一关。自定义试跑不会替代正式提交，也不会暂停倒计时。

## 源码构建

在Windows PowerShell运行 `./source/build.ps1`。生成独立 `Feng_C语言练习器_ver1.3.exe`。编译器、AvalonEdit和语言资源均内嵌，第三方许可证保留在source目录。

## 旧版更新器兼容

旧版更新器兼容附件 `Feng_C_Practice_ver1.3.0.exe` 与标准 ver1.3 EXE 内容及 SHA-256 完全一致，实际文件版本均为1.3.0.0。ver1.2.1、ver1.2.1.1、ver1.2.1.2使用这个兼容名称识别两段版本号；普通下载请选择ver1.3。
