# Feng's C语言练习器

**ver1.2.1.2 · Windows 本地 C 语言学习与自动评测工具**

> By Feng; 仅供学习使用。

90道普通练习、50关暗域星轨，内置C编译器和编辑器，支持语法着色、知识点学习、参考答案、随机评测及中英文诊断。

## 练习

普通练习：选题、学习知识点、编写程序，按Ctrl+Enter评测；右侧显示输入、实际与预期输出、耗时、退出码和中英文诊断。答案先提示再展开，导入前备份草稿。Ctrl+Z撤回，Ctrl+Y重做，Ctrl+S保存。

暗域：50关难度递增，每关8～30分钟，代码从空白自主编写；严格大于90分且编译、运行正常才解锁下一关。保留已有草稿、成绩、暗域进度与主题设置。
