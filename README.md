## 使用与功能

选题后编写程序，Ctrl+Enter提交评测。支持错题本、失败用例并排对比、自定义输入、点击编译错误跳转、多步撤回重做、代码答案提示及导入、自动保存。设置提供中英双语、明暗主题、界面与代码独立字号及一键更新。

暗域限时8～30分钟，全部代码须自主键入，通关前答案锁定，编译运行正常且严格大于90分才可进入下一关。
