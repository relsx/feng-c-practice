# ver1.1 暗域处决动画素材

> By Feng; 仅供学习使用；Email：feng111@bupt.edu.cn

`executioner-v2.png`：本项目使用内置 image_gen 工具生成的透明 RGBA 人物插画，1536×1024。图像在程序内作为独立人物层；刀刃、封印、斩光、火花与字幕由 WPF 动画绘制，图片没有作为一张整屏静态画面替代动画。

`smoke.png`、`spark.png`：Kenney Particle Pack 1.1 的透明烟雾和电光素材，分别来自 `smoke_05.png`、`spark_04.png`。来源：[Kenney Particle Pack](https://kenney.nl/assets/particle-pack)。授权：CC0；原始授权文件见 `Kenney-License.txt`。保留作者 Kenney Vleugels 及原始贡献者信息。

人物生成提示（内置工具模式）：

> Use case: stylized-concept. Asset type: high-resolution transparent character layer for an animated dark fantasy game-over screen, displayed on a 2560x1600 laptop screen. Generate a single ORIGINAL intimidating, stylish hooded executioner / dark knight character, waist-up portrait in a 3:2 landscape canvas with generous transparent margins. Truly transparent RGBA background, no scenery. Character faces camera, shoulders broad, slightly crouched ready posture, both armored hands visible near lower chest in a poised ready stance. Do NOT include any weapon: a separate animated blade will be composited in code. Face inside a deeply shadowed charcoal hood is a sculpted dark iron mask with two narrow crimson glowing eyes. Extremely refined layered blackened metal armor, ornate etched silver filigree and engraved crimson rune details, deep burgundy torn cloak, realistic fabric weave and weathered brushed steel, rich hand-painted / cinematic game concept art polish with clean crisp edges. Dramatic crimson rim light and restrained cold silver highlights make armor readable against black, ominous mysterious atmosphere, premium high-budget game aesthetic. Keep all head, shoulders, hands and cloak visible, no cropped face. No blood, no injury, no victim, no text, no logos, no watermark. This is a compositing asset, not a screenshot or UI mockup.
