# ver1.2.1.1 使用说明

By Feng · 仅供学习使用。

## 运行与外观

双击 `Feng_C语言练习器_ver1.2.1.1.exe`，需要 x64 Windows 与 .NET Framework 4.8 或更新版本。内置 C 编译器、编辑器与动画资源，无需另装 C 环境。

点击右上角齿轮 → 外观，可选择“明亮 · 蓝白”或“深色 · 夜蓝”。立即生效并保存，下次启动沿用；暗域始终使用暗蓝色。代码字号在设置里选择14、16、18、20、22、24，普通练习与暗域共用。主题切换不清空代码、光标或撤回历史。

移除了系统标题栏：拖动上方空白处可移动窗口，双击可最大化/还原；右上角依次为最小化、最大化/还原、关闭。弹窗可用右上角×或下方返回/完成按钮关闭。窗口边缘可调整大小；最大化按屏幕工作区铺满。

## 图标与练习

鼠标悬停在图标上显示中文说明。齿轮为设置，书本为知识点，代码符号为提示/参考答案，圆圈i为评分说明。编辑区弯箭头为撤回/重做，下箭头托盘为导入，软盘为保存，回转箭头为重置，右下角文档为评测报告。灰显表示当前不可使用。

选择题目，阅读要求和示例，在编码区编写程序，按 Ctrl+Enter 或点击“编译并评测”。右侧查看实际输入、实际输出、预期输出及中英文诊断。报告图标可查看全部用例、简洁度与完整报告，并导出TXT。

Ctrl+Z 撤回，Ctrl+Y / Ctrl+Shift+Z 重做，Ctrl+S 保存源代码。答案先显示提示，展开后可一键导入；导入前备份原草稿。普通练习失败仅显示得分警告，高分庆祝约1秒。

## 暗域

左下角进入星轨闯关，50关按节点横向推进，每关8～30分钟。先读知识点再开始，代码从空白自主键入，不能粘贴、拖入或导入答案。得分严格大于90分且编译/运行正常才解锁下一关，完整答案通关后仅供复盘。

学习、设置与切换窗口时继续计时，评测耗时不计入答题时间。结束尝试后可重新开始。暗域失败动画保留，Esc可提前淡出。

## 设置、更新与记录

设置中的软件更新支持自动检查正式GitHub Release，发现新版后由用户手动下载并更新。下载检查文件大小、SHA-256与内嵌版本，更新助手等待旧程序退出后替换并保留`.previous`备份。网络异常不影响离线练习。

本版保留ver1.2.1的草稿、最高分、字号与暗域进度，设置文件新增外观选项。旧版设置没有外观项时默认明亮。测试使用独立目录，不写入用户的练习记录。
