# Feng's C语言练习器 ver1.1.1 使用说明

> By Feng; 仅供学习使用；Email：feng111@bupt.edu.cn

双击 `Feng_C语言练习器_ver1.1.1.exe` 运行。适用于x64 Windows，需要.NET Framework 4.8或更新版本。C编译器、代码编辑器与动画素材均内嵌EXE，可离线使用。

## 普通练习

左侧选择题目，阅读要求后自行编写C程序，按Ctrl+Enter或点击“编译并评测”。右侧可逐一查看28组测试的输入、实际输出、预期输出、耗时与诊断。完整报告可从“查看结果与报告”打开。

编译失败、运行失败或得分低于60分时，右侧出现得分警告，底部分数标为醒目颜色。普通练习不会播放处决动画，也不会弹出强制中断编辑的失败窗口。直接修改并重新评测即可；成功后警告自动清除。

新增“知识点学习”，与“提示 / 标准答案”并列：

- “本题学习”：显示当前题目的学习目标，以及按题号顺序首次出现的语法、函数和用法。
- “相关基础回顾”：回顾本题用到、此前题目已引入的知识，并标明首次出现题号。
- 首次出现按题号顺序判断，不根据个人是否做过某题判断；跳题时也可回顾基础。
- 知识窗口讲解概念与常见问题，不提供答案导入；原有提示及标准答案功能仍保留。

撤回：Ctrl+Z；取消撤回：Ctrl+Y或Ctrl+Shift+Z。支持连续多步。切题会清空本题撤回历史，避免把上一题代码带入。Ctrl+S保存源文件；草稿自动保存。字号可选14～24，代码与结果区可拖动分隔条调整。

## 打开动画

主窗口约0.8秒淡入，完成后欢迎说明约0.5秒淡入。应用内的知识点、答案、报告、说明、确认及错误提示窗口也有约0.5秒淡入。动画只改变透明度，不改变代码、光标或选区的位置。淡入过程中关闭窗口不会留下等待任务。

系统提供的文件打开、保存对话框沿用Windows自身显示效果。

## 闯关模式

左下角“闯关练习 · 50关”进入独立暗色界面。通关前可学习知识点，但不能看完整答案；代码从空白自主键入，禁止粘贴、拖入或导入。自己的草稿可保留并重试。

50关依次解锁，每关3～10分钟。只有得分严格大于90分且编译、运行正常才能解锁下一关；90分整不能通关。完整答案仅已通关时可复盘阅读。

学习窗口、切换其他窗口或关闭界面时继续计算截止时间；评测提交本身不消耗答题时间。失败后可重新开始，保留自己的代码。闯关的编译失败、运行失败、低于60分或超时仍触发约4.4秒精细处决动画；Esc可提前淡出返回。

## 记录与版本

本补丁继续读取和保存 `%LOCALAPPDATA%\CPracticeLab-ver1.1`，保留ver1.1的普通练习草稿、历史分数与闯关进度。测试使用独立目录，不混入正常使用记录。ver1.1和更早程序仍保留。

软件左上角可打开 [GitHub仓库](https://github.com/relsx/feng-c-practice)。ver1.1.1已公开发布，可从仓库的Releases页面下载。

完整包包含源代码、编译脚本、许可证、更新日志和验证记录。在Windows上运行`source/build.ps1`可重新生成EXE。
