# ver1.3.1 使用说明

By Feng · 仅供学习使用

双击独立EXE即可运行，内置C编译器。需64位Windows及.NET Framework 4.8。

普通题按11个递进阶段排列，题号连续为1～150。左侧可按题号、中文或英文标题搜索，按阶段筛选。建议从第一题开始，综合项目位于148～150题。旧题可在题号对照表中定位。

书本图标打开知识点；代码图标先显示提示，再展开标准答案并可导入。导入前备份原草稿。新出现的语法按当前课程顺序标记，已学内容可复习。

Ctrl+Enter正式评测；终端图标支持自定义输入试跑。右侧查看结果，失败时可并排比较输出或点击原始编译诊断跳转；自定义试跑不计分。普通题总分上限15000。

设置中可切换中文/English、明暗主题及独立的界面字号和代码字号。撤回重做、错题本、自动保存等原功能保留。

学习数据沿用原本地目录，不清空草稿、成绩、错题与暗域进度。题号仅是展示位置，存储标识固定，因此重排后原记录仍属于同一道题。

暗域50关保持原内容、8～30分钟限时及严格大于90分的通关条件。全部代码自主输入，阅读和自定义试跑不暂停计时。

旧版可在设置→检查更新获取ver1.3.1，软件内下载、校验、替换并重启；保留原学习数据。
