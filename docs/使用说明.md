# ver1.2.1 使用说明

> By Feng; 仅供学习使用；Email：feng111@bupt.edu.cn

## 开始使用

双击 `Feng_C语言练习器_ver1.2.1.exe`。适用于x64 Windows，需要.NET Framework 4.8或更新版本。主窗口约0.8秒淡入，欢迎说明与应用弹窗约0.5秒淡入。编译器与编辑器均在EXE中，无需另装C编译环境。

普通练习仍有90题：选择题目、学习知识点、编写代码、按Ctrl+Enter评测，在右侧查看输入、实际/预期输出与中英文诊断。普通模式失败时显示得分警告；高分播放庆祝动画。Ctrl+Z撤回，Ctrl+Y或Ctrl+Shift+Z取消撤回。完整报告可单独查看或导出。

## 暗域 · 星轨闯关

从左下角进入，50关分为微光初醒、星屑阵列、符文回廊、星轨推演、深空试炼五章。起步采用与普通练习30～40题相近的循环、数位处理；后续逐步引入数组、字符串、矩阵、常用算法和项目。每关8～30分钟，同阶段可能使用相同限时。

上方的每颗星代表一关，连线表示推进路线。点击已解锁星点选关；用左右箭头、滚轮或底部滚动条浏览。鼠标悬停可查看题名、限时和解锁状态。倒计时开始后可浏览星轨，选关操作锁定，导航始终保持暗色。

先打开“知识点学习”：包含目标、语法首次出现讲解、解题步骤、常见错误和边界检查。完整答案仍在通关后开放复盘。点击“开始 / 重试”才开始计时，代码从空白自主键入，禁止粘贴、拖入和答案导入。自己的草稿可以保留重试。

只有得分严格大于90分且编译、运行正常，才能解锁下一关。90分整不能通关。查看知识点、打开设置、切换窗口或关闭闯关界面仍按真实截止时间计时；评测耗时不消耗答题时间。点击“结束本次挑战”可结束当前尝试。编译/运行失败、低于60分或超时保留闯关失败动画，Esc可提前淡出。

## 设置

主界面右上角或暗域右上角点击“设置”。

- 编辑显示：直接点击14、16、18、20、22、24六档字号按钮，即时同步两个模式并保存。字号只改变编辑器字体，不通过缩放整个界面实现。
- 软件更新：自动检查开关、检查状态、手动检查、新版说明、下载进度与手动更新入口。
- 项目与作者：GitHub地址、打开仓库、发布记录、更新下载目录和软件内联系方式。

## 检查更新与直接更新

默认在关闭启动欢迎说明后自动读取官方仓库的最新正式Release。成功结果缓存6小时，程序运行期间每小时检查一次缓存时效；“检查更新”可立即联网。无需登录或提供令牌。失败只在设置内提示，不影响本地练习。

只有GitHub正式版本高于本地版本时，才启用“下载并更新 · 将重启”。点击并确认后，软件下载官方Release中的EXE，显示进度，核对文件大小、SHA-256与EXE版本，全部通过后再重启替换。下载中可取消。闯关或评测进行时，需要先结束，再更新。

替换前在当前EXE所在目录准备新文件；独立更新助手等待原进程退出，再原子替换并启动新版。原EXE保存在同目录的 `.exe.previous` 文件，启动指令失败时尝试还原。备份可手动复制为新的.exe后运行；不要在新版正在运行时强行覆盖。下载或校验失败时不替换当前程序。

当前目录必须可写，其他程序也不能锁定EXE。若目录不可写，软件保持运行并提示；已下载文件可通过“打开更新下载目录”找到，另存到可写目录后运行。仅支持当前用户权限下的便携EXE替换，不会请求管理员权限。

ver1.2.1已作为正式版发布。软件比较GitHub最新正式版与本地版本；相同版本显示已是最新，以后有更高版本时才启用更新按钮。

更新请求仅获取公开Release信息和安装文件，不上传草稿、代码、成绩、邮箱或闯关进度。

## 数据与兼容

- 普通练习继续使用 `%LOCALAPPDATA%\CPracticeLab-ver1.1`，兼容ver1.1/ver1.1.1草稿与成绩。
- 新暗域记录：上述目录中的 `challenge-ver1.2.1`。关卡已重排，旧暗域的 `challenge` 文件夹保留，不将旧成绩直接用于解锁新关。
- 设置：`settings-ver1.2.1.tsv`；更新缓存与下载：`updates`。更新不删除这些记录。
- 验证使用独立临时目录，发布包不包含个人使用记录。ver1.2.1已在GitHub公开发布。

## 未来发布更新的约定

正式标签采用 `ver主版本.次版本.补丁号`，如ver1.2.2；Release附件优先命名为 `Feng_C_Practice_ver1.2.2.exe`，也接受对应中文程序名。EXE文件版本必须与标签一致。附件需有GitHub的sha256 digest，或附 `SHA256SUMS.txt`，每行写“64位哈希值  文件名”。仅有源码压缩包时不能直接更新。

实现参考：[GitHub Release API](https://docs.github.com/en/rest/releases/releases#get-the-latest-release)、[请求频率限制](https://docs.github.com/en/rest/using-the-rest-api/rate-limits-for-the-rest-api)。
