# ver1.2.1.2 使用说明

## 外框与图标

主界面保留融合顶部，可拖动上方空白区域、使用最小化/最大化/关闭。其他应用窗口使用Windows默认标题栏、边框和阴影，通过系统×或窗口内“完成/返回”关闭。它们不再绘制另一层圆角窗口轮廓，内部玻璃卡片不受影响。

图标可悬停查看中文含义。鼠标点击不改变按钮布局，Tab键导航仍有焦点提示。设置、知识点、提示、答案、撤回/重做、导入、保存及报告功能保留。

## 两套独立字号

在设置里分别选择：

- 界面字号：12、13（标准）、14、15、16，调整标题、题目、标签、说明和按钮文字。
- 代码字号：14、16、18、20、22、24，只调整编码区和代码预览。

字号即时生效并自动保存，不改变Windows系统级设置。界面文字变大时，相关行高、侧栏和弹窗尺寸同步调整；弹窗内容过长时可滚动，暗域在较矮窗口下压缩说明区域并保留滚动。代码坐标、光标和撤回记录独立保留。字号越大，同屏可见内容越少，可根据屏幕缩放选择适合的组合。

## 一键更新

软件检查正式GitHub Release，只有高于当前四段版本号的版本才启用“一键更新并重启”。点击后自动完成：下载官方EXE、检查文件大小与SHA-256及EXE版本、立即保存草稿、等待旧程序退出、备份为`.exe.previous`、替换并启动新版。

普通可写目录无需管理员权限。受保护目录按需弹出Windows系统授权；授权写入完成后，普通权限协调进程负责重启软件。取消授权或下载校验失败时保留原EXE，可重试；下载期间可以取消。请先结束正在进行的评测或闯关再更新。

ver1.2.1.2已作为正式Release公开发布。已安装ver1.2.1或ver1.2.1.1的用户，可在设置中点击“检查更新”，再选择下载更新。ver1.2.1的兼容附件名称保留ver1.2.1，但实际程序内容与版本为ver1.2.1.2。新版设置中使用“一键更新并重启”完成以后更高版本的更新。

## 练习

选题后阅读题目、示例和知识点，编写程序，Ctrl+Enter评测；右侧显示实际与预期输出，中英文诊断及完整报告可查看。Ctrl+Z撤回，Ctrl+Y或Ctrl+Shift+Z重做，Ctrl+S保存。

暗域50关保留8～30分钟限时，从空白自主编写。严格大于90分且编译运行正常才解锁下一关。草稿、成绩、暗域进度、明暗主题与代码字号沿用上一版。
