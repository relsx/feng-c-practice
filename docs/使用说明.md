# Feng's C语言练习器 ver1.0.1

> By Feng; 仅供学习使用；Email：feng111@bupt.edu.cn

双击 `Feng_C语言练习器_ver1.0.1.exe` 即可开始。适用于 x64 Windows，需 .NET Framework 4.8 或更新版本。首次评测会自动释放内嵌的 C 编译器，之后可以完全离线使用。

## 开始练习

1. 在左侧选题，或输入题目名称 / 题号搜索。建议先完成基础题，再按“进阶一”至“进阶五”学习，最后挑战三个综合项目考试。
2. 阅读要求与示例，在编码区编写完整 C 程序。字体可选择 14 至 24，右侧结果区域与编码区之间的分隔条可以拖动。
3. 点击“编译并评测”，或按 **Ctrl+Enter**。每次评测运行 8 组边界数据和 20 组随机数据，右侧显示具体输出与诊断。
4. 右侧下拉框可切换全部测试用例。“查看结果与报告”打开详细测试表、编译信息、简洁度评分和完整报告，并支持导出 TXT。
5. 遇到困难时点击“提示 / 标准答案”：先读提示，再点击“展开标准答案”；需要时点击“一键导入编码区”。当前草稿先自动备份，再导入答案。

草稿自动保存。**Ctrl+S** 将代码保存为文件；Tab 插入四个空格；Enter 按当前缩进换行；Ctrl+Z 撤销，Ctrl+Y 重做。导入普通文件使用编码区工具栏的“导入”。

## 题库学习路线

| 题号 | 内容 |
| --- | --- |
| 01–60 | 输入输出、条件判断、循环与数论、基础数组、字符串与矩阵 |
| 61–64 | 函数、指针与递归 |
| 65–75 | 二分、数组合并与去重、众数、子段和、滑动窗口、前缀和、矩阵运算 |
| 76–80 | 子串、字符压缩、括号匹配、大整数加法、结构体排序 |
| 81–83 | 链表、栈与队列 |
| 84–87 | 网格路径、硬币动态规划、最长递增子序列、迷宫广度优先搜索 |
| 88–90 | 学生成绩管理、仓储订单、图书借阅综合项目考试 |

每个项目考试需要实现可处理连续命令的完整程序，遵循题目规定的输入输出协议。测试会覆盖查询、更新、拒绝操作以及状态统计。

## 分数与输出

每题满分 100：随机正确性 60、边界正确性 20、运行质量 10、简洁度 10。简洁度包含有效行数、有效代码大小各 5 分，完整规则见软件“评分说明”和“更新日志”。左下角累计得分取每题历史最高分之和，题库满分 9000。

只输出题目规定的结果，不要输出“请输入”等额外提示，不要使用 `system("pause")`。整数精确比较，浮点允许绝对误差 0.0001；每组限制 3 秒、256 MiB 和约 64 KiB 输出。编译错误会提供 `answer.c:行号`，方便定位。

## 本地数据与源代码

新版数据保存在 `%LOCALAPPDATA%\CPracticeLab-ver1.0.1`：`drafts` 为草稿，`scores.tsv` 为最高分，`answer-import-backups` 为答案导入前的草稿备份。新版使用独立记录，旧程序继续使用原记录。

`source` 文件夹提供完整源码、开源许可、TinyCC 二进制与对应源码。运行 `source/build.ps1` 可重新构建本版本；它将输出到本文件夹，仅替换本文件夹中的 ver1.0.1 EXE。发布的 EXE 已内嵌 AvalonEdit DLL，使用时不必携带 `source` 文件夹。

验证报告与 2.5K 主界面预览一并提供。高分屏检查覆盖模拟布局缩放与原生分辨率渲染；没有逐一测试所有笔记本与多显示器组合。
