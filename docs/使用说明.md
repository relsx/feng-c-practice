# ver1.3 使用说明

By Feng · 仅供学习使用

## 开始

双击 EXE，在左侧选题后编写代码。Ctrl+Enter 正式评测；Ctrl+Z 撤回，Ctrl+Y / Ctrl+Shift+Z 重做。原有草稿、最高分、暗域记录会继续读取。无需把新版复制到旧版目录。

## 错题本

左侧“错题本”打开独立窗口。正式评测编译失败或有未通过用例时自动记录，按普通练习/暗域区分，重复失败合并到同一题。保留最近一次失败的代码、诊断、得分、时间、种子和最多三个代表性失败用例。

可搜索题号或中英文题名，筛选待巩固、已解决或全部。重新正式提交并全用例通过后自动标为已解决，之后再失败会重新打开。仅因简洁度扣分而全部用例正确的提交不会新增错题。暗域能否通关仍按原有 >90 分规则判断。

“重新练习”进入对应题目并保留当前草稿。“恢复失败代码”用于普通练习，先备份当前草稿再恢复失败快照；暗域快照仅供阅读，不提供导入。删除错题记录不会删除原草稿和最高分。新错题从 ver1.3 的正式提交开始积累，不会凭旧分数推测历史错误。

## 失败用例对比

正式评测后，点击右侧结果栏的双栏图标。默认只看失败用例，也可显示全部用例。输入显示在上方，预期和实际输出并排展示。红色突出首个不一致的输出项，缺少项用 ∅ 标记。

勾选“显示空格与换行”后，空格显示为 ·，制表符为 ⇥，换行为 ↵。这些仅用于显示，不会改变数据和判题规则。整数、浮点容差、文本大小写及忽略空白的规则沿用旧版。运行失败时也应阅读诊断和退出码。

## 自定义输入

点击编码区工具栏的终端图标，在上框输入数据，点击运行。使用打开窗口时的代码快照，输出显示在下框；需要修改代码时，关闭窗口修改后重新打开。

输入最多64 KiB，运行每次最多3秒、256 MiB，输出限制64 KiB。支持停止、编译诊断和定位。标准输入采用UTF-8，中文原始输入/输出不会因界面语言改变。该功能不记分、不更新错题、不解锁关卡，也不代替正式提交。

暗域须先开始挑战才能打开试跑，倒计时继续；输入框只接收测试数据，不能将代码导入闯关编辑区。

## 点击错误跳转

编译失败后，单击右侧原始 `answer.c:行:列:` 诊断行即可跳转。也可点击准星图标打开诊断列表，再点一条诊断。没有列号时回到该行开头；列号超出当前行时定位行尾，失效的行号不会把光标移到错误位置。

弹窗关闭后恢复代码编辑焦点。英文编译原文仍保留；中文界面同时提供中文解释。运行错误可能没有具体源码行号，这时可通过失败用例定位。

## 中文 / English

设置 → 语言 / LANGUAGE，选择“简体中文”或“English”，立即生效并作为下次启动的默认语言。切换不需联网，不重建编辑器，不改变代码、原始程序数据、撤回历史或闯关截止时间。代码和用户数据保持原文，系统文件选择窗口的系统按钮语言由 Windows 决定。

界面字号与代码字号继续独立设置。副窗口沿用系统外框，内部保持蓝白/暗蓝玻璃卡片与打开关闭过渡动画。

## 本地文件

原数据根目录：`%LOCALAPPDATA%\CPracticeLab-ver1.1`。错题在 `mistakes-ver1.3`，恢复前备份在 `mistake-restore-backups`。首次运行才会创建本版所需目录。本次交付包不含开发测试记录，也没有清空你的学习数据。

ver1.3已作为正式Release公开发布。旧版用户可在设置中手动“检查更新”并更新到本版；未来更新继续使用软件内下载、校验、替换和重启。旧版更新器兼容附件 `Feng_C_Practice_ver1.3.0.exe` 与标准 ver1.3 EXE 内容及 SHA-256 完全一致，实际文件版本均为1.3.0.0。ver1.2.1、ver1.2.1.1、ver1.2.1.2使用这个兼容名称识别两段版本号；普通下载请选择ver1.3。
