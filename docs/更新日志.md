# ver1.3.1 更新日志

2026-11-02 · By Feng · 仅供学习使用

1. 普通练习由90题扩充到150题，新增60道生活情境练习；答案、提示、知识点与中英文内容同步更新。
2. 150题按难度与知识依赖重新编排为11个阶段：输入输出、分支、循环、数组、字符流、矩阵、函数与指针、组合算法、数据结构、动态规划、综合项目。综合项目位于148～150题。
3. 149份参考答案仅使用stdio.h；链表教学保留必要的stdlib.h。减少对其他库的依赖，练习基础语法与手写遍历、比较、排序。
4. 扩大题目展示区并向上利用留白，兼顾编辑空间与不同字号；修复英文动态文案和选题绑定显示。
5. 知识点首次出现位置随新顺序重算；新增getchar/putchar、EOF讲解，提供重排前后题号对照表。
6. 显示题号与存储标识分离，原有草稿、分数、错题继续关联原题。搜索、答案、报告与知识点显示新题号。
7. 暗域50关的题目、代码、学习内容、时间和通关规则保持不变；原ver1.3程序保留。
